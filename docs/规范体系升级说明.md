# FlyWow Codex 工程规范体系升级说明

## 基线

本替换包基于 `simbiwu/Skynet-FlyWow` 的 `main` 分支提交：

`f6935bc0975d1f0ba7cd15630089f1db2c326d26`

## 结构

工程保留三个 Skill 入口：

1. `skynet-flywow-coding-standard`：现有强制编码规范入口，原 `SKILL.md` 保持不变，新增任务专项 references。
2. `source-based-practical-teaching`：现有源码教学 Skill，文件保持不变。
3. `flywow-engineering-workflow`：新增设计、实施、审计、复杂度治理和调试工作流。

保留原有 `check_repository.py` 与 `test_check_repository.py`，不替换其 Lua 注释、HotUpgrade 专项和仓库基线检查逻辑。新增独立 `check_skill_structure.py` 与对应单测，避免为增加 Skill 结构检查而重写已有大型检查器。

## 主要增强

- AGENTS 增加明确 Skill 路由和最小设计强制原则。
- Coding Standard 增加五份任务专项 references；原主 Skill 的既有编码规则保持原样。
- 新增 Engineering Workflow 主 Skill 和五份 references。
- 增加反向必要性审计、重复防御审计、状态/数据冗余审计和架构重置方法。
- 将调用者、测试、样例和内部文档的存在与设计必要性明确区分。
- 更新 D004，确认 Coding Standard references 也是强制规范补充。
- 更新质量门禁和 CI，执行 Skill 结构检查。

## 合同保护

本次只修改规范、文档、质量检查脚本/测试和 CI 门禁配置。未修改 FlyWow 业务源码、公开 API、协议、错误码、模块运行行为或第三方源码。

工程决策 D001-D003、D005-D011 的内容保持原有含义；D004 仅补充 Coding Standard references 的强制属性。Gateway、Navigation、HotUpgrade 等既有合同不在本次变更范围内。

## 安装

在 FlyWow 仓库根目录解压 ZIP，允许覆盖同名文件。建议先备份当前工作区，尤其是 `AGENTS.md`、`docs/工程决策.md`、`docs/质量门禁.md` 和 `.github/workflows/quality.yml`。

本包不包含原 Coding Standard 和 Teaching Skill 的主文件，因为它们在本次升级中保留原样；解压不会删除它们。

## 验证

在仓库根目录运行：

```bash
python3 -m unittest discover -s scripts/quality -p 'test_*.py'
python3 scripts/quality/check_repository.py
python3 scripts/quality/check_skill_structure.py
```

完整 build、Gateway runtime tests 和样例运行不属于本次纯规范变更的本地验证范围；应由项目 CI 在真实工程环境中执行。
