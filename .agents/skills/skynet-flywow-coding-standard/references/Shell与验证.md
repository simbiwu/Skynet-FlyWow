# Shell 与验证补充规范

本文件补充现有 Coding Standard 中的 Shell、构建和测试规则。

## Shell

- 使用 `set -euo pipefail`。
- 根据脚本自身位置解析仓库路径。
- FlyWow 自有 Shell 脚本支持从任意当前工作目录启动；固定运行目录由脚本自行切换。
- 对外脚本说明参数、路径基准、关键步骤和副作用。
- 不为一条简单命令机械拆出多个包装脚本。
- 第三方源码携带的脚本保持上游内容，不得为统一风格而修改。

## 验证

- 运行与本次变更和受影响模块匹配的 build/test。
- 区分 build、run、test 和 not verified。
- 测试应验证业务行为和真实边界，不只绑定内部类、Helper 或历史调用顺序。
- 内部结构改变时，可调整内部测试以继续验证行为；公开 API、协议和兼容合同测试不得擅自删除。
- 不通过关闭检查、减少断言、吞错或跳过测试让结果变绿。
