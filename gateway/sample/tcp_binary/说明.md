# TCP Binary Frame Sample

从 FlyWow 根目录执行：

    bash gateway/sample/tcp_binary/run.sh ../skynet

若缺少协议产物，先从仓库根目录运行 bash server/protocol/build_protocol_lesson_03_frame_sync.sh。要求 Node.js 22 或更高版本可用。成功标记：FLYWOW_GATEWAY_SAMPLE_OK mode=binary。

客户端经 TCP 完成握手，直接发送线上字节：uint16 大端长度头后接 Protobuf Envelope wire bytes。Gateway 拆除长度头并按 Protobuf 合同解码；handler 回 FrameJoinResponse 并主动推送 FramePushResponse。客户端校验真实收到的两条消息后断开。当前 Gateway 使用 Protobuf 业务格式；本 sample 展示二进制 TCP 帧，不表示独立原始二进制业务协议。
