# TCP Protobuf Sample

从 FlyWow 根目录执行：

    bash gateway/sample/tcp_protobuf/run.sh ../skynet

若缺少协议产物，先从仓库根目录运行 bash server/protocol/build_protocol_lesson_03_frame_sync.sh。要求 Node.js 22 或更高版本可用。成功标记：FLYWOW_GATEWAY_SAMPLE_OK mode=protobuf。

客户端经 TCP 完成 FlyWow 握手，按 Protobuf 字段合同编码 FrameJoinRequest 与 Envelope，再放入 uint16 大端长度帧。Gateway 解码并投递给 handler；handler 回 FrameJoinResponse 并主动下发 FramePushResponse。客户端解码并校验收到的两条消息。
