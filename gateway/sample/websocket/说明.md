# WebSocket Sample

从 FlyWow 根目录执行：

    bash gateway/sample/websocket/run.sh ../skynet

若缺少协议产物，先从仓库根目录运行 bash server/protocol/build_protocol_lesson_03_frame_sync.sh。要求 Node.js 22 或更高版本可用；缺少 Gateway Native 时脚本调用现有构建脚本。成功标记：FLYWOW_GATEWAY_SAMPLE_OK mode=websocket。

H5 SDK 建立 WebSocket 并完成 FlyWow 握手。客户端发送 binary message，内容为 Protobuf FrameJoin Envelope。Gateway 解码并投递给 handler；handler 回 FrameJoinResponse 并向该连接主动下发 FramePushResponse。客户端校验两条真实消息后关闭连接。
